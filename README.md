# SMPTE 丢帧时码合版核对台

一个不依赖后端 API 的纯前端核对工具，用于检查 29.97 fps（`30000/1001`）和 59.94 fps（`60000/1001`）SMPTE drop-frame 时码合版结果。

## 功能

- 固定输入格式：`HH:MM:SS;FF`，分号明确表示丢帧时码。
- 支持 1–200 个片段，每片包含唯一 `id`、`sourceIn`、`sourceOut`、`recordIn`。
- `sourceOut` 为排他端，时长按整数帧计算：`sourceOut - sourceIn`。
- `recordOut = recordIn + durationFrames`，拒绝零时长、负时长和触碰 24 小时回绕点的录制区间。
- 校验非整十分钟边界的禁用帧：
  - 29.97：`MM:SS;00`、`MM:SS;01`（`MM % 10 !== 0` 且 `SS=00`）不存在。
  - 59.94：`MM:SS;00` 至 `MM:SS;03` 不存在。
- 任一字段或结构非法时拒绝整份输入；页面保留上次合法结果，但标记为非当前结论。
- 重叠按半开区间交集计算：`min(recordOut, 既有覆盖端) - recordIn`。长片包住短片时，短片的重叠就是它自身的帧数，不会延伸到长片结束；表格、色带与导出结果一致。
- SVG 标尺与表格共享同一份分析结果；导出 JSON 直接序列化该结果，不重新计算。
- 标尺刻度严格小于 24 小时回绕点，全日视图和滚动到日末都能正常渲染。
- 数值 id 与字符串 id 可在同批次混用；屏幕上字符串 id 带引号显示（`1` 与 `"1"` 可区分），导出 JSON 保留原始类型。
- 第一处真实空隙或重叠会在摘要、标尺和表格中标出。
- 来源交付预演使用丢帧时码选择非空半开录制区间，在整数帧坐标上切成贡献片段集合恒定的最大区间，逐段标记空隙、唯一来源或多来源冲突。
- 每个贡献片段都按自身 `recordIn/sourceIn` 偏移精确映射回原片起止帧；剪辑师只能从当前冲突段的现有贡献片段中选择一个，空隙或未裁决冲突会阻止导出。
- 来源清单仅在片段身份相同、原片坐标连续且录制坐标连续时合并；导出项按录制顺序排列，并与选择、裁决共同绑定生成它们的分析快照。输入更新或非法编辑不会把旧裁决套用到新结果。

## 来源复用审计

录制时间线即使没有缝隙，也可能把同一批原始画面重复用在不同位置。每份有效分析都会附带一份只读的来源复用审计：

- 把各片段的 `[sourceIn, sourceOut)` 投到同一来源轴，端点扫描生成被至少两片覆盖的最大半开区间。
- 活动片段 id 集合一变就必须断开，即使复用计数相同也不合并；数值 id 与同字面字符串 id 保持不同身份。
- 每段列出来源起止整数帧与时码、覆盖片段 id，并按各片段自己的 `recordIn` 平移出对应录制区间。
- 点击某段证据会同时高亮来源轴上的该段和录制时间线上的全部落点；再次点击取消。
- 来源帧、录制帧都用整数裁决，时码仅作显示；段端点不超过日内最后一帧，日末边界不回绕。
- 复用报告通过「下载复用报告」单独下载，与「导出核对 JSON」互不影响；原导出结构逐项不变。
- 非法编辑保留两套旧视图并标记过期；新的合法输入会原子替换接缝视图与复用视图。

## 来源交付预演

剪辑师输入丢帧时码形式的录制选区后，工具只依据整数帧坐标分析半开区间 `[recordStart, recordEnd)`：

- 端点扫描把选区划成活动贡献片段集合恒定的最大区间；活动集合为空是空隙，一个片段是唯一来源，两个及以上是多来源冲突。
- 半开区间在同一边界先处理离场再处理入场，因此贴边片段不会被误判为覆盖，相邻端点不会错误接合。
- 每段列出录制起止、时长和全部现有贡献片段；每个贡献片段的录制段会按自身来源/录制偏移映射出原片起止。
- 唯一来源自动采用，冲突段必须显式选择一个贡献片段；空隙不能通过裁决绕过。仍有空隙或未裁决/非法裁决时不允许导出。
- 全部合法裁决后，来源清单按录制顺序生成；相邻结果只有在片段身份（区分数值 `1` 与字符串 `"1"`）、原片坐标和录制坐标都连续时才合并。
- 分段对象由分析器生成后直接传给时间线、选择状态和导出，不重复计算。选择或裁决只接受所属快照中的片段；非法编辑保留旧预演但禁止操作和导出，新合法输入原子替换快照并使旧预演失效。
- 来源清单有独立导出按钮；原核对 JSON 和复用报告的结构保持不变。

## 输入示例

```json
{
  "rate": "30000/1001",
  "clips": [
    {
      "id": "A",
      "sourceIn": "01:00:00;00",
      "sourceOut": "01:00:05;00",
      "recordIn": "00:10:00;00"
    }
  ]
}
```

`id` 可以是非空字符串或安全整数，并且在整份输入中必须唯一。未知根字段、未知片段字段、重复 id、非法结构都会导致整份拒绝。

## 丢帧算法

普通换算会把一分钟误算为 1800（或 3600）个标签帧；drop-frame 时码在每个非整十分钟跳过一组帧号：

- 30 nominal：每 10 个标签分钟包含 `10 × 1800 - 9 × 2 = 17982` 个真实帧。
- 60 nominal：每 10 个标签分钟包含 `10 × 3600 - 9 × 4 = 35964` 个真实帧。
- 30 fps 日帧长：`24 × 6 × 17982 = 2589408`。
- 60 fps 日帧长：`24 × 6 × 35964 = 5178816`。

解析时累计 `00:00` 到当前标签分钟之间发生过的非整十分钟数量，再减去对应跳帧数；反算时按十个真实分钟的块进行整数除法，避免浮点和普通时分秒换算错误。

## 测试

`src/lib/timecode.test.ts` 覆盖：

- 整十分钟边界；
- 小时边界；
- 非整十分钟首个合法帧和禁用首帧；
- frame → timecode → frame 与 timecode → frame → timecode 往返；
- 24 小时边界。

`src/lib/analysis.test.ts` 覆盖 recordOut、按录制位置排序、空隙、重叠、完全包含与同一长片内多个短片的半开区间交集、混合类型 id 的身份保持、非法输入拒绝和导出快照。

`src/lib/timeline.test.ts` 覆盖全日缩放、日末滚动及各缩放档位下标尺刻度不触碰 24 小时回绕点。

`src/lib/reuse.test.ts` 用逐帧成员集合预言机覆盖来源复用审计：包含、交叉、三重覆盖、相邻端点不接合、同计数但成员集合变化必须断开、数值与字符串混合 id 身份、日末边界不回绕，以及复用报告与原核对导出的结构隔离。

`src/lib/delivery.test.ts` 在小整数帧域穷举半开选区并逐帧预言机核对空隙/唯一/冲突分段、贡献集合及原片/录制坐标；同时覆盖冲突裁决、空隙阻断、旧裁决非法、身份与双坐标连续才合并、数值/字符串 id 和半开始码校验。

`src/App.test.tsx` 做页面联动验收：点击复用证据同时高亮来源段与录制时间线全部落点、非法编辑保留两套过期视图、新合法输入原子替换两套视图、复用报告单独下载且原导出逐项不变；来源交付覆盖冲突裁决、空隙阻断、合并导出，以及非法编辑冻结旧预演、新快照使旧选择与裁决失效。
